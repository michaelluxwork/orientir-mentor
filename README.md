# Ориентир — кабинет наставника

Учебное веб-приложение для проверки куратором. Подопечные, цели, встречи, история прогресса и отчёт за период. Исходные примеры полностью вымышлены.

## Проверка

Адрес: https://orientir.178-255-126-110.sslip.io/

Доступ к отдельному аккаунту передаётся куратору в домашнем задании. Паролей в репозитории и на странице входа нет. Регистрация, загрузка файлов и публичное создание аккаунтов отсутствуют. Вносите только вымышленные данные.

После входа можно создать подопечного, добавить цели и встречи, оценить прогресс, посмотреть историю и сформировать отчёт. Для PDF используется печать отчёта средствами браузера. Показатели без оценки отличаются от нулевой оценки; параллельные изменения проверяются по версии записи.

## Короткая инструкция наставнику

1. Откройте приложение и войдите с выданными логином и паролем. Для проверки используйте только вымышленные имена, цели и заметки.
2. Нажмите **Добавить подопечного**, заполните имя и фокус работы, затем **Сохранить**. Откроется карточка подопечного; позже её можно открыть через раздел **Подопечные**.
3. В карточке нажмите **Добавить цель**. Укажите название, критерий результата и при необходимости срок; сохраните. Это согласованная цель, а не автоматическая оценка человека.
4. Нажмите **Записать встречу**. Укажите состоявшуюся дату, тему, заметки и следующие шаги. Для замера прогресса выберите цель и оценку от0 до100. Можно оставить оба поля пустыми: отсутствие оценки отличается от нуля. Нажмите **Сохранить**; встреча появится в истории.
5. Чтобы исправить данные подопечного, нажмите **Изменить** вверху карточки. Для цели или встречи используйте **Изменить** рядом с нужной записью, внесите правки и сохраните. Удаление требует отдельного подтверждения. Если запись уже изменилась в другой вкладке, прочитайте предупреждение и заново откройте актуальную форму.
6. В карточке нажмите **Отчёт**. При необходимости задайте даты и нажмите **Показать**. Отчёт содержит датированные оценки, заметки и следующие шаги. Кнопка **Печать / Сохранить PDF** открывает печать браузера: выберите сохранение в PDF и сохраните файл. Перед передачей просмотрите его содержимое. Отправки отчёта другим людям из приложения нет.

Динамика показана датированными оценками и полосами прогресса. Средняя оценка учитывает только оценённые цели; рядом указано их количество. Снижение оценки сохраняется. Записи и доступ сохраняются после обычного обновления страницы и перезапуска сервиса.

## Локальный запуск

Проверено с Python3.12 локально и Python3.14 на VPS. Создайте отдельное окружение и установите закреплённые зависимости.

Windows:

```powershell
py -3 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe manage.py migrate --noinput
.venv\Scripts\python.exe manage.py seed_demo
.venv\Scripts\python.exe serve.py
```

macOS/Linux:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python manage.py migrate --noinput
.venv/bin/python manage.py seed_demo
.venv/bin/python serve.py
```

Адрес локально: http://127.0.0.1:4365/. Случайные локальные учётные данные создаются в .state/demo-access.txt. Каталог .state не включать в Git или архив. Для проверки: python manage.py test mentoring.

## Размещение

Django 5.2 LTS, SQLite, Waitress и WhiteNoise. Профиль vps-demo требует отдельный каталог состояния вне исходников, секрет из окружения и точный HTTPS-хост. Шаблоны deploy/ рассчитаны на отдельного системного пользователя, loopback-порт и собственный Nginx virtual host. bootstrap.py предназначен только для первой установки: он отказывается изменять уже существующее размещение. Приложение не запускается при исчезновении установленной базы; перезапуск не сбрасывает записи и пароль.

Ограничения: это учебная работа, не сервис для ведения реальных клиентских записей. Нет регистрации, email, файловых вложений и автоматического PDF-сервера. Резервные копии SQLite создаются локально командой backup_mentor; копия на том же диске не защищает от потери всего сервера.
