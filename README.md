# Ориентир — кабинет наставника

Учебное веб-приложение для проверки куратором. Подопечные, цели, встречи, история прогресса и отчёт за период. Исходные примеры полностью вымышлены.

## Проверка

Адрес: https://orientir.178-255-126-110.sslip.io/

Доступ к отдельному аккаунту передаётся куратору в домашнем задании. Паролей в репозитории и на странице входа нет. Регистрация, загрузка файлов и публичное создание аккаунтов отсутствуют. Вносите только вымышленные данные.

После входа можно создать подопечного, добавить цели и встречи, оценить прогресс, посмотреть историю и сформировать отчёт. Для PDF используется печать отчёта средствами браузера. Показатели без оценки отличаются от нулевой оценки; параллельные изменения проверяются по версии записи.

## Локальный запуск

Python 3.10–3.14. Создайте отдельное виртуальное окружение, установите requirements.txt, затем выполните:

```sh
python manage.py migrate
python manage.py seed_demo
python serve.py
```

Адрес локально: http://127.0.0.1:4365/. Случайные локальные учётные данные создаются в .state/demo-access.txt. Каталог .state не включать в Git или архив. Для проверки: python manage.py test mentoring.

## Размещение

Django 5.2 LTS, SQLite, Waitress и WhiteNoise. Профиль vps-demo требует отдельный каталог состояния вне исходников, секрет из окружения и точный HTTPS-хост. Шаблоны deploy/ рассчитаны на отдельного системного пользователя, loopback-порт и собственный Nginx virtual host. bootstrap.py предназначен только для первой установки: он отказывается изменять уже существующее размещение. Приложение не запускается при исчезновении установленной базы; перезапуск не сбрасывает записи и пароль.

Ограничения: это учебная работа, не сервис для ведения реальных клиентских записей. Нет регистрации, email, файловых вложений и автоматического PDF-сервера. Резервные копии SQLite создаются локально командой backup_mentor; копия на том же диске не защищает от потери всего сервера.
